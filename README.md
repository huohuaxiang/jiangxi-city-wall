# 降曦城城墙 · 可交互 3D 场景

一个单文件、零外部请求的 WebGL 城墙场景。打开 `index.html` 就能跑，不联网也行。

![封面](cover.jpg)

## 这是什么

降曦城北段城墙。1200 米实体段，两端各 300 米低模延展（纯雾色，看不到端点）。

- **墙身**：100 米高，底宽 24 米裙墙斜面收到顶宽 9 米，10 条银白水平分带压在墙上
- **塔楼**：20 座，间距 60 米，方身带垛口，顶上红黑双旗
- **垛口**：131 个，模数 4.2 米
- **城棱**：倒三角棱柱，从墙面真凸出去 5 米，尖端朝下（射击位）
- **法师高台**：10 座，120 米一档、和塔楼错开 30 米，铁艺栏杆加中央发光圣杯
- **火炮**：67 门，铜绿炮身、黑铁箍、龙头炮口
- **飞行平台**：悬在墙内侧的悬挑桁架
- **环境**：多云天空、远山、城内尖顶群、护城河、士兵

## 怎么玩

| 操作 | 效果 |
|---|---|
| 拖拽 | 转视角 |
| 滚轮 | 缩放 |
| 空格 | 切晴 / 阴 / 雨 / 雾 |
| N | 切昼夜 |
| 1-5 | 外景 / 内景 / 细节 / 炮位 / 鸟瞰 |
| R | 重置视角 |

## 技术

- 单 HTML，three.js r160 内联（669KB），**零外部请求**
- 全部程序化生成：几何、砌缝贴图、天空云层、旗帜摆动、雨雪雾
- 几何是确定性函数，同样参数永远得到同样的场景
- 实例化渲染：塔楼、垛口、城棱、火炮、士兵都是 InstancedMesh

## 验收

自检脚本 17 条全过：

- 墙体包围盒 100.01 米、长度 1200 米
- 塔楼 20、间距 60
- 高台 10、与塔楼错位 30
- 炮数 = ceil(垛口/5) + 2×塔楼
- 炮间最小距 10.8 米
- 垛口间距严格等于模数 4.2
- 垛口、城棱都不撞塔楼
- 白像素比 0.827、红像素 0.004、暗像素 0.009
- 差分可见性 0.357
- 零运行时错误

## 本地打开

直接双击 `index.html` 即可。不需要任何构建步骤，没有依赖。
